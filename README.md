# JavaScript Objects - 5 Small Learning Programs

This folder contains 5 simple, independent JavaScript files designed to help you understand core Object concepts step-by-step.

## Included Programs:

1. `01-object-basics.js`: Literals, Constructor functions, Dot vs. Bracket notation, Methods, and `this`.
2. `02-object-static-methods.js`: `Object.keys()`, `Object.values()`, `Object.entries()`, `Object.assign()`, and `Object.freeze()`.
3. `03-spread-and-destructuring.js`: Object Spread (`...`), basic destructuring, aliasing, and default values.
4. `04-nested-objects-and-arrays.js`: Working with nested objects, nested arrays, and nested destructuring.
5. `05-json-parse-stringify.js`: `JSON.stringify()` (Object to String) and `JSON.parse()` (String to Object).

## How to Run:

Run any program directly using Node.js:
```bash
node 01-object-basics.js
node 02-object-static-methods.js
node 03-spread-and-destructuring.js
node 04-nested-objects-and-arrays.js
node 05-json-parse-stringify.js
```

Or run via NPM shortcuts:
```bash
npm run prog1
npm run prog2
npm run prog3
npm run prog4
npm run prog5
```
